# Northwind Systems — Incident Response Policy

_Fictional sample document for testing. Not a real company._

## §1. Incident Response Plan

§1.1 Northwind maintains a documented incident response plan that defines
severity levels, roles and responsibilities, and communication procedures for
security incidents.

§1.2 The incident response plan is reviewed and updated at least annually.

## §2. Reporting

§2.1 All employees are required to report suspected security incidents to the
security team without delay.
